# Naming screen voice script

Use the same narrator and delivery as the intro. Record each line separately as an MP3 in `godot/assets/intro/audio/`. The corresponding line plays when its field receives focus; the on-screen text remains available while recordings are absent.

**Malton name first.mp3**  
Before Malton fell, someone called your name. What did they call you?

**Malton name last.mp3**  
And the family name on your old records?

**Malton name corpse.mp3**  
One day, the living may need to describe your corpse. In one word, what will they call it?
