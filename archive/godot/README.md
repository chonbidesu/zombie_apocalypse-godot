# Godot artwork archive

- `menu_preview/` holds earlier character room designs, alternate atlases, reference captures, and art prompts.
- `intro/` holds superseded intro artwork, specimen animations, art notes, and the browser preview.
- `assets/` holds superseded minimap atlases, panels, and character sprite sheets.

The live character room uses the selected atlases in [godot/assets/character_creation](../../godot/assets/character_creation).

The [archived intro preview](intro/preview.html) reads current artwork from [godot/assets/intro](../../godot/assets/intro) and its earlier specimen frames from the archive. Archived Godot scenes and manifests record their original project paths.
